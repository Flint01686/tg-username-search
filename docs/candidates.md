# Ники из масок

Имена из `fsbXX`, `fsbXXX`, `zovXX`, `zovXXX`, `fsoXX` и `fsoXXX`. Пустая страница `t.me` сюда не попадает как «свободен»: у `fso222` она такая же, как у случайного имени, а клиент пишет «имя пользователя уже занято».

Профиль есть, ник у пользователя:

- fso000
- fso111
- fso555
- fso777
- fsb222
- fsb333
- fsb444
- fsb888
- zov222
- zov888
- zov999

Страница без карточки, в клиенте уже занято:

- fso222
- fso888
- zov000

Профиля нет, на Fragment лот со статусом Available:

- zov777

Свободным ник называется только после `account.checkUsername` в режиме `--mt`.
