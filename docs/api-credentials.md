# Как получить api_id и api_hash

Скрипт читает их из файла `.env` в корне репозитория. В чат и в git эти значения класть не нужно: `.env` уже в `.gitignore`.

1. Открой [my.telegram.org](https://my.telegram.org) и войди номером телефона. Код придёт в Telegram.
2. Открой раздел **API development tools**.
3. Если приложения ещё нет, создай его. Название любое, например `username-check`. Платформа — Desktop. Короткое имя тоже любое, латиницей.
4. На странице будут два поля: **App api_id** (число) и **App api_hash** (длинная строка).

Создай `.env` рядом с `.env.example`:

```text
TG_API_ID=12345678
TG_API_HASH=0123456789abcdef0123456789abcdef
```

Без кавычек и без пробелов вокруг `=`.

Дальше один раз войти из корня репозитория:

```text
python check.py --login
```

Скрипт спросит номер и код из Telegram и сохранит сессию в `tg.session`. Этот файл тоже не коммитится. После входа проверка маски тем же методом, что поле в настройках:

```text
python check.py --mt zovXX zovXXX
```
